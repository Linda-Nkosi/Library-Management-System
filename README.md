# Java Library Management System

A clean, modular **Java** application built to streamline library administrative workflows, manage book collections, and maintain user loan records.

---

##  Features

-  **Book Management:** Add, edit, remove, and search books by Title, Author, or ISBN.
-  **Member Management:** Register new users, view active borrower profiles, and track loan histories.
-  **Circulation Control:** Issue books with automated due dates and track incoming returns.
-  **Search & Filter:** Quick lookup functionality across the entire library catalog.
-  **Data Persistence:** Integrated with [MySQL / SQLite / File I/O] for reliable data storage.

---

##  Built With

- **Language:** Java (JDK [11/17/21])
- **GUI / Architecture:** [Swing / JavaFX / Console CLI]
- **Database / Storage:** [MySQL / SQLite / File I/O]
- **Build Tool:** [Maven / Gradle / Standard SDK]
